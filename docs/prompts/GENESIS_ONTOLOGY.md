# Genesis ontology invariant

This file is a concise binding reference for future development agents.

- A Soul begins to exist at first activation / Genesis.
- Conversation is not required for existence.
- `soulId` is the stable machine identifier; it is not the Soul's human-facing name.
- A newly activated Soul may be unnamed.
- Genesis does not imply another participant was present.
- First encounter is a later independent event with its own timestamp and provenance.
- Naming is a later independent event with its own timestamp and provenance.
- Activation, first encounter, and naming may happen close together in lived experience, but the data model must not force them to be one event.
- Legacy Genesis v1 records preserve their historical fused first-meeting semantics and must not be rewritten to fit the newer ontology.
- New Genesis work should use the activation-first v2 model.
