# Evolution Log — Model-switch criteria before model-switch verdict

**Date:** 2026-08-27

## Context

M5 established that continuity criteria should be fixed before a continuity verdict. M6 creates a stronger temptation to move the goalposts because a different model will inevitably change observable style, reasoning cadence, and other phenotype.

## Decision

Before the first real model-switch run, freeze the evidence-bearing comparison dimensions and the regression procedure.

The M6 comparison uses the same durable dimensions already established in M5: identity, autobiography, user model, relationship, and covenant/constraint. It requires the same frozen Soul State reference across the compared runs and keeps runtime/model configuration visible.

Model phenotype observations are recorded separately rather than silently normalized away or automatically counted as Soul drift.

No numerical identity score is introduced. Engineering evidence remains dimension-specific, and the Haisu Test remains a separate longitudinal judgment.

## Principle

> **Model-switch criteria must be fixed before the model-switch verdict.**

A model change is the independent variable. Soul State must remain frozen for a clean comparison, and missing or ambiguous evidence must remain unresolved rather than being coerced into pass/fail.
