# Explicit user-request agency evidence requires real human interaction

Date: 2026-09-07
Issue: #295

## Invariant

An `explicit-user-request` Agency trigger cannot be asserted from a label, runtime presence, or arbitrary text object. Its first DSH producer must begin at the existing fail-closed DSH human-message boundary and retain the resulting Experience identity and provenance lineage.

A real human message is still not sufficient by itself. The adapter uses a deliberately narrow explicit-action-request predicate. Greetings, statements, context-only interaction, ambiguous questions, synthetic messages, and plugin-originated events produce no Agency trigger evidence.

The derived `AgencyTriggerEvidence` is descriptive evidence only. It carries `authority: none` and grants no permission, authorization, execution, scheduling, polling, memory write, or canonical Soul-state mutation.

## Consequence

Presence remains distinct from attention and initiative. Interaction remains distinct from an explicit request for initiative. Even a valid explicit request is only evidence that can enter the separate Agency eligibility boundary; it is not authorization to act.
