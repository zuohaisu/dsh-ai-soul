# DSH continuity digest is read-only cognition context

Issue: #376

The bounded continuity digest may be rendered for DSH cognition only as a synchronous presentation projection of current canonical Soul State.

It does not create truth, memory, appraisal, reflection, governance authority, permission, or execution authority. Opaque `relationship.state` remains excluded because its item-level ontology is not canonical enough to support continuity inference.

The rendering contract is deterministic, bounded by the underlying continuity digest contract, source-attributed, omitted when empty, and zero-mutation. Runtime integration must reuse the already-supported synchronous `systemPrompt.context().text()` composition boundary; it must not introduce asynchronous retrieval or silently broaden memory authority.
