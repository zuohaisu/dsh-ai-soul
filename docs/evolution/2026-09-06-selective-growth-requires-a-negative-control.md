# Selective growth requires a negative control

Date: 2026-09-06
Issue: #273

## Decision

A real-runtime selective-growth proof is incomplete unless it includes both a positive significant interaction and an ordinary/control interaction.

The positive path must still show traceable Experience → candidate → proposal → independent human review → persisted canonical mutation → next-turn model-visible use. The control path must show that an ordinary interaction produced no promotion proposal and left canonical cognition unchanged.

## Invariant

Selective growth != interaction accumulation.

A system that can learn an important interaction but also promotes every ordinary interaction has not demonstrated selective long-term memory.

## Evidence boundary

The verifier requires explicit real-runtime observations and durable references for both paths. It does not create the control interaction, infer success from CI, or manufacture runtime evidence. Missing control evidence is incomplete; observed control promotion or canonical-state mutation is a falsifying failure.

Raw interaction history, Experience Records, canonical cognition, and governance evidence remain distinct stores and concepts.
